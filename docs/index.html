Install in one line.

Terminal
~ % curl -fsSL https://raw.githubusercontent.com/Luis-Sejer/snicker-gif/main/install.sh | sh

It installs Snicker into your Applications folder, with no admin password, and opens it. Run it again any time to update. Prefer clicking? Download the zip instead.

Questions

Does it really work in Microsoft Teams?

Yes. Teams only accepts a GIF pasted as a file, and Snicker always puts the file on the clipboard alongside the image data, so the GIF arrives animated.

Is it free?

Yes. Snicker is free and open source under the MIT license.

Why does macOS say it can’t verify the developer?

Snicker isn’t notarized with a paid Apple developer account. The install command avoids the warning. If you downloaded the zip, open System Settings → Privacy & Security, scroll down and click Open Anyway.

Where do the GIFs come from?

From KLIPY’s GIF library. Your searches go to KLIPY and nowhere else.

Which Macs does it run on?

Macs with Apple Silicon running macOS 26 or later.

How do I start it automatically?

Open Snicker’s ⋯ menu and turn on Launch at Login.
